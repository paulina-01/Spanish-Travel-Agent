Special consonants — CH · LL · Ñ
CH
(che)
Sounds like the "ch" in English cheese.
¡Chévere! — "Cool / Awesome"
LL
(elle)
Sounds like the "y" in yes. Regional variation applies.
lluvia — "rain"
Ñ
(eñe)
Sounds like "ny" in canyon. A completely separate letter from N.
niño — "kid / boy"
The tricky trio — H · J · G
H
(silent)
Always completely silent — never pronounced (does provide a pause)
hola → "oh-lah", not "hoh-lah"
J
(hoh-ta)
A strong rasping "h" — never like English J.
jugo → "juice" (sounds like "hoo-go")
G
(heh)
Like J before E/I. Hard G before A/O/U or closed vowel after Ü.
gato → hard G  |  pingüino → hard G

Sílaba tónica
"Every Spanish word has one syllable that carries the stress. Spanish classifies words by where that stress falls — learn the three types and you can read any word aloud."
The three word types by stress position
Agudas — tonic syllable is the last syllable
ca·fé can·ción a·mor
Llanas / Graves — tonic syllable is the second-to-last syllable
me·sa lá·piz can·tan
Esdrújulas — tonic syllable is the third-to-last syllable
pá·ja·ro mú·si·ca sí·la·ba
Identify the type
robot → Aguda  ·  zapato → Llana  ·  teléfono → Esdrújula  ·  cantar → Aguda

La tilde
"The written accent mark doesn't create the stress — it just marks when the word breaks the default rule for its type."
When does each type get a tilde?
Agudas get a tilde if they end in vowel, N, or S
café ✓ canción ✓ compás ✓ amor ✗ robot ✗ cantar ✗
Exception: ends in S preceded by a consonant → no tilde (robots)
Llanas get a tilde if they end in a consonant other than N or S
lápiz ✓ árbol ✓ dólar ✓ mesa ✗ cantan ✗ lunes ✗
Exception: ends in S preceded by a consonant → does get tilde (bíceps)
Esdrújulas — always get a tilde, no exceptions
pájaro ✓ música ✓ mágico ✓ teléfono ✓
