The hook
"Flores para ti vs. estudio español por mis padres — one is purpose, the other is cause."
Core concepts
PARA: purpose · destination · deadline · opinion · recipient
POR: cause · duration · medium · exchange · space
Side-by-side contrast with real examples
Key vocabulary
Para = purpose / goal Por = cause / time Flores para ti Por la mañana Por videollamada

Practice drill
Fill in para or por: Estudio español ___ mis padres. / Este paquete es ___ Diego.
Culture note — Think of PARA as an arrow pointing forward to a goal. POR is the ground you walked on to get there.
